# Echoes of Ember

**Echoes of Ember** la game hanh dong 2D pixel art duoc phat trien bang Unity 6 va C#.
Nguoi choi dieu khien Kael trong chien dich gom 5 man: Ember Ruins, Crystal Depths, Ashen Forge, Shadow Citadel va Ember Throne.

## Chuc nang chinh

- Campaign Hub va lua chon man choi.
- Di chuyen, nhay, tan cong, phong thu va chien dau voi quai.
- HUD hien thi HP, Mana, Ember va Kills.
- Hotbar ky nang, Inventory/Equipment, Quest Book va Spell Book.
- Fireball duoc mo khoa bang Fireball Scroll va tieu hao Mana.
- Popup phan thuong ruong, Game Over va Level Complete.

## Cong nghe

- Unity 6 (6000.5.4f1)
- C#
- Windows / DirectX 11

## Mo project

1. Cai Unity Hub va Unity 6000.5.4f1.
2. Clone repository.
3. Mo thu muc project bang Unity Hub.
4. Mo `Assets/Scenes/CampaignHub.unity` va nhan Play.

## Cau truc chinh

- `Assets/`: scene, script, sprite, prefab va asset game.
- `Packages/`: package Unity.
- `ProjectSettings/`: cau hinh project Unity.

> Thu muc `Library`, `Temp`, `Logs`, `Builds` va file IDE duoc bo qua vi Unity tu tao lai tren may cua nguoi dung.
